# Machine Learning Practicum

This repository contains a collection of exercises and practical work completed throughout the **Machine Learning** learning and practicum process.

The practices cover several fundamental stages of a machine learning workflow, starting from data exploration and preprocessing to data visualization and the implementation of various machine learning methods.

## 📚 Topics Covered

- Python for Machine Learning
- NumPy
- Pandas
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Data Visualization
- Statistical Analysis
- Machine Learning Algorithms
- Model Evaluation

## 🛠️ Tools & Technologies

- **Python**
- **Jupyter Notebook**
- **Google Colab**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**
- **Scikit-learn**
